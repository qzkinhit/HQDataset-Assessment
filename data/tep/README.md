# Classic Tennessee Eastman files

Files `d00.dat` to `d21.dat` are the training files and `d00_te.dat` to `d21_te.dat` are the test files of the Braatz distribution, http://web.mit.edu/braatzgroup/TE_process.zip. Each row holds 52 process variables. The file `d00.dat` is stored with rows and columns swapped. A test fault file holds the fault from row 161. `LICENSE` holds the license of the distribution.
